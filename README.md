# Accident-Data-Analysis-Dashboard-
An interactive Accident Data Analysis Dashboard that visualizes road accident trends, severity, locations, and contributing factors. Provides meaningful insights through charts, graphs, and KPIs to identify accident patterns, high-risk areas, and support data-driven decisions for improving road safety.

## About This Project

This project is a dashboard about road accident casualties. A dashboard is a page that shows information using numbers, charts, and filters.

The dashboard helps people explore casualty data in different ways. It shows totals by injury severity, vehicle type, month, road type, area, light condition, and weather condition.

The dashboard shows **400,617 total casualties**.

## What the Dashboard Shows

### Casualties by severity

| Severity | Number of casualties |
|---|---:|
| Fatal | 6,417 |
| Serious | 57,261 |
| Slight | 336,939 |
| **Total** | **400,617** |

In the figures shown, slight casualties are the largest group.

### Casualties by vehicle type

| Vehicle type | Number of casualties |
|---|---:|
| Car | 319,789 |
| Bike | 32,313 |
| Goods van | 32,025 |
| Bus | 12,220 |
| Other category shown | 4,270 |

In the figures shown, cars have the highest number of casualties.

### Other charts

The dashboard also shows:

- A comparison of casualties by month for 2021 and 2022
- Casualties by road type, such as single carriageways and roundabouts
- A comparison of rural and urban casualties
- A comparison of daylight and darkness
- Casualties in different weather conditions

## Dashboard Filters

The filters on the right side of the dashboard let users choose a vehicle type, weather condition, or road type. The charts then update to show the selected information.

## How to Use It

1. Open the dashboard file in the program it was made with.
2. Choose an option from one of the filters on the right.
3. Look at the charts and numbers to see the results.
4. Change or clear the filter to explore another category.
